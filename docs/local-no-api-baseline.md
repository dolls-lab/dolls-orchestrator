# 本地无 API 语音闭环基线

> 测试日期：2026-09-06  
> Profile：`local-no-api`  
> 结果：通过

## 环境

- Apple Silicon macOS 26.6.2；
- Python 3.9.6 项目虚拟环境；
- `mlx-whisper 0.4.3`；
- `mlx 0.29.3`；
- 模型：`mlx-community/whisper-small-mlx`；
- 模型 revision：`45f3915923c7a79a5a5b5a7d909d39aeb0e5630e`；
- TTS：macOS `say`，`Tingting`；
- 输出：24 kHz、单声道、16-bit PCM WAV。

## 测试输入与结果

输入为系统声音生成的普通话样本：“你好，这是一段语音测试。”

- ASR 输出：`你好,这是一段语音测试。`；
- ASR 耗时：2713 ms；
- 固定 LLM 首个文本片段：138 ms；
- TTS 首音频：625 ms；
- TTS 合计耗时：1210 ms；
- 端到端耗时：3924 ms；
- 输出音频时长：4.04 秒；
- DeepSeek 网络请求：0 次。

本次数字仅用于确认链路可运行，不作为正式 P50/P95。正式性能结论需要真实麦克风录音和多轮独立样本。

## 已发现并处理的问题

1. 首次模型下载超过默认 60 秒 ASR 超时。模型缓存完成后推理约 2.7 秒；首次安装时可临时提高超时。
2. `mlx-whisper` 对文件路径输入依赖 `ffmpeg`。适配器已改为直接读取 PCM WAV、下混、转换采样宽度并重采样到 16 kHz，因此项目无需引入 FFmpeg。
3. 受限沙箱中的 `say` 可能返回成功但写出零帧音频。适配器现在会拒绝空音频；在正常本机环境中已验证能够生成非空声音。
